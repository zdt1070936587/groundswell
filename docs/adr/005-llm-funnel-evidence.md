# ADR-005 LLM 分层漏斗与证据强制

## 背景

每天有数百个活跃话题，全部交给强模型分析成本不可控；LLM 打分存在幻觉。

## 决策

三级漏斗：

1. 规则筛选：只保留需求 / 技术 / 消费 / 政策四类话题，且区域内增速与提及量达标；
2. 初筛：便宜模型（或启发式）给出 1–5 分，只保留前 N；
3. 深度分析：强模型对 (话题, 区域) 输出结构化 JSON，每日上限 `GS_LLM_DEEP_DAILY_CAP`。

约束：

- 输出用 Pydantic 校验；失败重试一次，仍失败则丢弃。
- 每个分值必须引用本次提供的证据条目 id，引用不存在的 id 或无引用 → 该分值置空；反方观点必填。
- 按 `input_hash`（话题、区域、prompt 版本、方法论版本、模型、证据集合）缓存，输入不变不重复调用。
- 所有调用写 `llm_usage`，当日成本达到 `GS_LLM_DAILY_BUDGET_CNY` 时熔断。
- 未配置 LLM 时走启发式分析器，保证流水线端到端可运行，结果标记 `model=heuristic`。

## 后果

- 成本可预测，初期每天几元到二十元量级。
- 所有结论可追溯到原文，便于人工复核与反馈闭环。
